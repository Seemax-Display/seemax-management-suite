SEEMAX MANAGEMENT SUITE - GUIDA RAPIDA

NOVITÀ VERSIONE 1.5
- MODALITÀ STANDARD: ogni modifica viene salvata subito nel database.
- MODALITÀ RAPIDA: le modifiche restano sul dispositivo; premere SALVA TUTTO prima di tornare alla modalità standard.
- QUOTATION PLANNER: resta utilizzabile in Modalità Rapida, ma non può salvare o caricare preventivi dall'archivio online.
- ATTIVITÀ: sono sempre locali e non vengono inviate al Foglio Google.
- DOCUMENTI: selezionare direttamente il file in Modalità Standard; il caricamento è sospeso in Modalità Rapida.
- STATI PRATICA: soltanto un amministratore può modificarli.
- OBIETTIVO FATTURATO: valore iniziale 500.000 euro, modificabile da Impostazioni.

1) PROVA
   Pubblica i file su GitHub Pages.
   Login ADMIN: admin.demo / DEMO-ADMIN

2) DATABASE
   Apri il Foglio Google > Estensioni > Apps Script.
   Incolla apps-script/Code.gs.
   Esegui setupSeemaxDatabase.

3) PUBBLICAZIONE APPS SCRIPT
   Nuovo deployment > Applicazione Web.
   Esegui come: Me.
   Accesso: Chiunque.
   Copia URL /exec.

4) COLLEGAMENTO
   Apri assets/js/config.js.
   Imposta demoMode: false.
   Incolla l'URL in appsScriptUrl.

5) GITHUB PAGES
   Settings > Pages > Deploy from branch > main > root.

Per tutti i dettagli apri docs/GUIDA_COMPLETA.md.
