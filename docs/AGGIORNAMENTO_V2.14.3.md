# Aggiornamento Seemax Management Suite 2.14.3 — documento storico

La versione 2.14.3 ha introdotto le schede organizzative dell'area Impostazioni e le politiche **Solo una volta** / **Sempre**.

La prima implementazione collegava però l'editor del Benvenuto a un secondo popup generico, separato dal messaggio grafico originario “Benvenuto nella Beta”. Questo comportamento è stato sostituito integralmente dalla versione 2.14.4.

Per installazione, migrazione e funzionamento corrente consulta:

- [AGGIORNAMENTO_V2.14.4.md](AGGIORNAMENTO_V2.14.4.md)
- [RAPPORTO_EDITOR_UNIFICATO_V2.14.4.md](RAPPORTO_EDITOR_UNIFICATO_V2.14.4.md)
- [ANALISI_FOGLIO_SEEMAX_V2.14.4.md](ANALISI_FOGLIO_SEEMAX_V2.14.4.md)

Non usare `upgradeSeemaxV2143` come riferimento operativo: nella release corrente è mantenuto soltanto come alias compatibile verso `upgradeSeemaxV2144`.
